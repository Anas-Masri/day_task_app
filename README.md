Day Task is a smart task and project management app designed to help you organize your day, track progress, and stay productive.

The app allows you to create multiple projects, break them down into clear tasks, and monitor each task’s status using a flexible workflow (To Do, In Progress, Done).
Day Task delivers a clean and modern user experience with support for dark mode, offline access, and automatic data synchronization.

✨ Key Features:

Create and manage daily tasks and projects

Task status tracking (To Do / In Progress / Done)

Due dates and priority levels

Tags for better organization and search

Kanban board and calendar views

Smart notifications and reminders

Dark mode support

Offline mode with automatic sync

Simple and intuitive UI

Day Task is your daily companion for better focus, productivity, and goal achievement.
